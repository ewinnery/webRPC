# WebRPC v1.0.1 — Hotfix Release

Обновленный патч-релиз с исправлениями таймеров, детекции рекламы и иконок.

---

## 📦 Файлы релиза

* **`webRPC.exe`** — Пересобранный C++ фоновый клиент (исправлены таймеры и фоллбэки иконок).
* **`webrpc-extension.crx`** — Упакованное расширение v1.0.1.

---

## 🛠 Исправления и изменения v1.0.1

* **Исправлен призрачный таймер (0:47):** При переходе с видео на обычные веб-страницы таймеры отсчета (`startTimestamp` и `endTimestamp`) теперь принудительно обнуляются.
* **Фильтрация рекламы (YouTube Ads):** Добавлена детекция рекламных роликов. Реклама на YouTube, прероллы и микро-плееры больше не сбивают статус активности.
* **Отображение логотипов сайтов:** Добавлен фоллбэк на Google Favicon API (`https://www.google.com/s2/favicons?domain=...&sz=128`), благодаря чему вместо плашки со знаком вопроса `?` всегда выводится 128x128 PNG логотип любого сайта.
* **Сборка C++ клиента:** В репозиторий добавлены необходимый исходный код библиотеки `discord-presence` и скомпилированный бинарник `webRPC.exe`.
